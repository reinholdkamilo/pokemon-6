# Pokémon 6 Game Rules

## Core Concept

Players must build a team of six Pokémon from Generation 1.

The team must defeat:

1. The 8 gym leaders
2. The Elite Four
3. The Pokémon Champion

The aim is to go undefeated.

## MVP Challenge

Build the six strongest Generation 1 Pokémon with balanced primary types.

## MVP Rules

1. Only Generation 1 Pokémon are allowed.
2. The player must select exactly six Pokémon.
3. No duplicate Pokémon are allowed.
4. A balanced team should avoid repeated primary types.
5. The team must have strong coverage against gym leaders, Elite Four members, and the Champion.
6. The result is either Win or Lose.
7. The game must explain why the team won or lost.

## Scoring Areas

- Base stat strength
- Type balance
- Gym leader coverage
- Elite Four coverage
- Champion coverage
- Weakness management
- Team variety
