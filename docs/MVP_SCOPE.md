# MVP Scope

## MVP Goal

Create a playable first version of Pokémon 6 where the player can search Generation 1 Pokémon, select a team of six, submit the team, and receive a Win/Lose result with basic explanation.

## Included in MVP

- Homepage
- Pokémon search
- Six team slots
- Local Generation 1 Pokémon data
- Submit team button
- Team scoring logic
- Win/Lose result
- Pokémon detail cards

## Not Included Yet

- Full battle simulator
- User accounts
- Online leaderboard
- Save games
- Animations
- Official artwork
- Multiplayer
- Mobile app
