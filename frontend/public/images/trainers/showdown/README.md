# Pokemon Showdown Trainer Sprites

This folder contains raw, unedited trainer sprites downloaded from:

https://play.pokemonshowdown.com/sprites/trainers/

The images are source assets for future regional trainer pools. They are not
automatically wired into gameplay.

Important:

- Keep source files unedited.
- Preserve `manifest.json` and `ATTRIBUTION.md`.
- Many sprites are not from the games and require appropriate artist credit.
- Curated gameplay pools should reference these files rather than duplicate
  them where practical.
